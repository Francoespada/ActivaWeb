# Activa Design — sitio web

Landing/portfolio profesional construido con HTML5, CSS3 y JavaScript vanilla.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño, responsive, componentes y animaciones.
- `script.js` — menú hamburguesa, scroll reveal, contadores y microinteracciones.
- `assets/franco.png` — retrato transparente suministrado para la presentación.

## Cómo usarlo
No requiere Node, npm ni frameworks.

1. Abrí `index.html` localmente para probarlo.
2. Para publicarlo, subí `index.html`, `style.css`, `script.js` y la carpeta `assets` al directorio público de tu hosting (por ejemplo `public_html`).
3. Si querés cambiar textos, colores o datos de contacto, editá `index.html` y las variables de `style.css`.

## Personalización rápida
Los colores principales están al principio de `style.css` en `:root`:
- fondo: `--bg`
- violeta principal: `--purple`
- violeta claro: `--purple-2`

El botón de WhatsApp actualmente usa el enlace mostrado en el perfil de Activa Design.
